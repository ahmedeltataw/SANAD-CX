SANAD CX — حزمة الواجهة

ارفع محتويات هذا المجلد إلى جذر استضافة ملفات ثابتة. الصفحات HTML، والصور والخطوط في assets.
الأنماط المحلية كلها في assets/css/styles.css، والبرمجة المحلية كلها في assets/js/main.js.
Bootstrap 6.0.0-alpha.1 وAOS 2.3.1 عبر روابط CDN المعتمدة، ولذلك يحتاج تحميلهما إلى الإنترنت. لم تُضمّن مكتبات بديلة أو تُغيّر الإصدارات.
تهيئة المظهر المبكرة وبيانات SEO تبقيان داخل HTML كما في النسخة المعتمدة. تحتوي صفحة 404 أيضًا تصريح CSS داخليًا قصيرًا لتعطيل الانتقال بين الصفحات كما في الأصل.

حالة التسليم: واجهة مكتملة محليًا؛ إرسال النماذج الفعلي يحتاج endpoint معتمدًا، والنشر وcanonical/sitemap يحتاجان الدومين والاستضافة. درجة Lighthouse لم تُقس بقرار المالك.
للمعاينة المحلية: فك ضغط الحزمة بالكامل، ثم افتح index.html مباشرةً بالمتصفح؛ لا تحتاج إلى خادم أو تثبيت أي برنامج. أبقِ مجلد assets بجانب صفحات HTML. تحتاج مكتبات CDN فقط إلى اتصال بالإنترنت.
ضبط الاستضافة: HTTPS، صفحة404.html مع حالة HTTP404 للمسارات غير الموجودة، وأنواع MIME الصحيحة، وضغط gzip/Brotli.
إشعارات تراخيص المكتبات والخطوط موجودة في THIRD_PARTY_NOTICES.md.
